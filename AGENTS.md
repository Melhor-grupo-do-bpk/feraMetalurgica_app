# Instruções para agentes de IA

As regras deste repositório ficam em [`CLAUDE.md`](CLAUDE.md) (espelhado
em `.cursorrules`), e o planejamento em [`docs/`](docs/README.md). Leia os
dois antes de qualquer alteração. Se você é o agente de uma trilha (T2 a
T8), leia também [`docs/orquestracao.md`](docs/orquestracao.md): branches,
worktrees, arquivos que você pode tocar, contratos e handoffs. Este arquivo existe só para que
ferramentas que procuram `AGENTS.md` (Codex, Gemini, etc.) encontrem essas
regras. Não coloque regras aqui.
